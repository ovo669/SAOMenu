# SAO Menu(SAO 菜单)

SAO Utils 风格的圆形菜单界面模组 · Minecraft 1.20.1 · Architectury(Forge + Fabric)

按 **O** 键(默认,可在按键设置改)打开刀剑神域风格的悬浮菜单:

- **世界保持全亮**(无遮罩),菜单悬浮在角色前方偏左上(锚点 38.9%W / 36.3%H,
  与 SAO-World 参考截图逐像素实测一致)
- 一列半透明圆形主按钮(技能 / 队伍 / 好友 / 设置),悬停变橙 `#EFA603`、图标反白
- **SAO 式动画**:打开时从按钮缩放弹出,整个菜单持续上下浮动,
  玩家卡与菜单项级联滑入,关闭时缩回消失
- 左侧玩家属性卡:玩家名、全身剪影、手持物品预览(左上角槽位 + 手持行)、
  Level / Experience / Health / Hunger / Armor / Strength / Agility / Resistance
  (大卡 9 行,小卡自动精简为 6 行)
- 血条板(GUI 较大时):生命条 + 饥饿条 + 血量/等级与护甲值双行文本
- **SAO 3D 环绕目标血条**:真正画在世界空间的三维弧带围着生物躯干(单薄壳体 +
  分离尾块 + 亮白包边),随生物移动实时跟随、有透视与环绕感;弧带中点恒定朝向相机,
  绕到生物背后也照样读表;玩家视线落在生物身上时才淡入显示(按生物角半径判定,
  近处占满屏幕也算看向),移开视线后淡出;血量下降时颜色由绿经黄、橙渐变到正红,
  受击瞬间提亮闪白;头顶另有正对相机的红色菱形标识,名称/血量文字画在 HUD 层
  (带深色底衬)。各图层几何互不重叠且颜色不透明,**兼容 Iris/Oculus 光影**——
  光影会把自建的 POSITION_COLOR 图元当作不透明几何写进 gbuffer 并忽略顶点 alpha
  与提交顺序,旧的多层半透明玻璃壳在光影下会整条退化成一堵白墙盖住血量读数
- 血条板下方状态效果图标行(原版药水效果贴图,菜单与 HUD 均显示)
- **SAO 时钟小部件**:顶部居中实时时钟(主题色镶边),12/24 小时制与日期显示
  可配;状态效果图标悬停显示名称与剩余时间
- **入世欢迎动画**:每次进入世界时播放 SAO Utils 风格开场——
  "Welcome to Sword Art Online !" 横幅落下淡入,下方 Message 面板缩放弹出
  (主题色左镶边),提示文字随后浮现,停留后整体淡出;可在设置界面开关
- **死亡碎裂特效**:生物被击杀时像动漫一样整体炸成蓝色多边形碎片——
  死亡当帧在包围盒体内爆散一批自旋碎片 + 中心叠加闪光,随后 4 tick 补少量残碎,
  碎片先悬浮再坠落、末段收缩淡出;同时隐藏原版倒地变红的死亡动画。
  碎片数量随体型缩放(26-190),密度可在设置界面调节(0.2x-2.5x)
- O 键层级返回(配置→菜单→游戏),物品栏滚轮切换快捷栏槽位
- 战斗反馈:受击时血条板闪红,血量低于 20% 时血条呼吸式红色脉冲,
  低于 25% 时屏幕边缘出现呼吸式红色危险晕影
- 队伍/好友菜单项(邀请玩家等)切换对应面板;好友面板的"成就图鉴"滚动列出
  全部已解锁成就(图标+名称+描述);物品栏底部快捷键提示行
- 玩家卡/血条板统计完整国际化(zh/en/ja/ko),随游戏语言切换
- 右侧白色菜单项(技能 / 装备 / 物品)带 ◀ 尾巴与连接环,"装备"下有武器 / 护甲 / 首饰二级菜单;
  **武器/护甲/首饰不再打开物品栏,而是直接在第三列列出当前已装备的物品**(一行一件:
  物品图标 + 名称,悬停高亮,空栏显示"暂无装备"),与 SAO-World 参考效果一致
- "技能"打开 SAO 属性面板:完整展示生命/护甲/韧性/攻击/攻速/击退/移速/幸运等
  全部核心属性(属性名随游戏语言,平台未注册的属性自动跳过)
- **SAO 风格物品栏**:菜单"物品/武器/护甲"打开自绘物品栏(3x9 主区 + 快捷栏 +
  护甲/副手槽),左键拿起/放下/堆叠/交换,右键拆分/放单个,Shift 一键转移
  (快捷栏↔主区,护甲自动入槽),数字键 1-9 交换快捷栏,Q 丢弃,
  左键拖放均分/右键拖放逐个放置,双击聚合同种物品,F 键副手交换,
  分类标签(全部/武器/护甲/材料)过滤高亮,关闭自动回收光标物品
- 底部 10 个圆点即物品栏:圆点内渲染真实物品图标(含数量),第 10 个为副手,悬停显示物品名
- 悬停主按钮/菜单项播放轻量 tick 音效;O 键再按一次关闭菜单
- **SAO 通知系统**:升级、低血量、**成就解锁**(替换原版 Toast 并隐藏
  "X 完成了成就"聊天消息,横幅带成就物品图标)时右上角滑入主题色镶边横幅,
  自动淡出;可在设置界面开关
- 队伍/好友面板接真实数据:scoreboard 队伍成员列表、Tab 在线玩家列表
- **模组设置界面**(菜单 → 设置 → 模组设置):**女神异闻录风格重做**——
  「设置背景.mp4」帧动画作背景(480x270@15fps 帧贴图集 ping-pong 播放),
  4 个斜切分类板(布局/战斗/界面/主题)从左侧级联滑入,悬停填充主题色;
  点击分类播放斜切色带转场,板体飞出、设置行带过冲逐条弹出;返回时反向转场。
  锚点 X/Y、菜单缩放、浮动幅度、碎裂密度、主题色、音效、隐藏原版快捷栏、
  SAO HUD、入世欢迎动画、死亡碎裂、时钟大小、跟随鼠标等全部配置项分四页管理,
  即时生效并保存到 `config/saomenu.json`
- **主题色**:色相 0-360° 可调,按钮高亮/菜单项悬停/圆点选中/通知镶边/设置界面全面跟随
- 音效取自 SAO Utils 素材:Launcher(打开)/ Click / Panel / Alert(关闭)
- 按原需求**不包含**右侧任务栏

## 安装

构建产物 `forge/build/libs/saomenu-forge-1.0.0.jar` 放进 `.minecraft/mods`:

- Forge 47.3.0+(需 Architectury API,已内嵌)

## 开发

```
gradlew build                 # 构建 Forge jar
gradlew :common:test          # 84 项单元测试(布局/配置/通知/欢迎动画/碎裂/目标血条 2D+3D)
gradlew :forge:runClient      # 启动 Forge 开发客户端

# 无头可视化校验:自动开菜单/队伍面板/好友面板/二级菜单/设置界面/物品栏、
# 触发升级通知、物品栏点击搬运自检,截图到指定目录后退出
# (同时写入 config/saomenu.json 验证持久化)
gradlew :forge:runClient -Psaomenu.preview=<输出目录>
```

## 结构

```
common/  布局数学 MenuLayout(纯逻辑,带单测)、SAOMenuScreen 渲染、按键、
        SAOConfig 配置持久化(带单测)、SAOSettingsScreen P5 风格设置界面
        (视频背景+斜切转场,替代旧 SAOConfigScreen)、
        SAONotification 通知系统(带单测)、SAOWelcome 入世欢迎动画(带单测)、
        SAODeathEffect 死亡碎裂编排(带单测)、SAOShardParticle 碎片粒子、
        SAOTargetBar 血条配色与形状纯函数(带单测)、SAOTargetBar3D 世界空间环绕血条(带单测)、
        SAOCombatHud 战斗 HUD、SAOInventoryScreen 物品栏、贴图音效资源
forge/   音效/粒子 DeferredRegister、平台桥接、世界渲染钩子、客户端初始化、9 个客户端 mixin
tools/gen_textures.py    PIL 生成全部 GUI 贴图(圆形按钮/图标/箭头/圆点)
tools/gen_particles.py   PIL 生成死亡碎裂的碎片与光晕粒子贴图
tools/gen_settings_bg.py 设置背景视频 → 帧动画贴图集(ffmpeg 抽帧+PIL 量化拼图)
```

素材来源:`SAO_Utils_2.2` 主题包(Click.wav / Panel.wav,转制为 ogg);
欢迎动画贴图取自 `SAO Utils Icon Set`(etc/welcome.png、background/message.png);
菜单样式比例参照 SAO_Utils_2.0 预览图与 SAO_Menu.styl(橙 `#eda60c`、白 `#f9f9f9`、圆按钮)。
